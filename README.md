# MTV Россия — обновление

Загрузите все файлы прямо в корень репозитория GitHub, БЕЗ создания папок:

- `index.html` — сайт
- `news.json` — лента новостей

Сайт сначала загружает `news.json`, затем при недоступности файла использует резервный источник Telegram.

GitHub Pages:
